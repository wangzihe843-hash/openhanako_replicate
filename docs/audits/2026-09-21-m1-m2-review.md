## 主任务复核与修复

- 试演复用一次性文本 HTTP 调用，没有工具参数或正式 AgentSession；取消/超时停止整个 fallback 链，结果只入既有工坊草稿，正式人设/示例/开场需分别采纳。
- 工坊既有保存函数会吞掉错误；为新流程增加严格错误传播和可见失败，保留旧调用兼容。补齐按角色/连接排队保存和重开前等待，避免关闭重开后旧快照覆盖新草稿。
- 初始角色卡资料和 canonical lore 必须在 Agent.init 之前落盘；失败清理本次新角色，保留既有创建路径。
- 新会话尾部原本会安排外观摘要模型调用。显式开场/空白入口抑制该调用，在 SessionCoordinator 注册前插入开场；恢复或传入既有 SessionManager 在创建前拒绝。没有使用 `session.firstMessage` 列表摘要字段冒充真实消息。
- 现有 session 创建失败处理只清 runtime 注册与资源，不提供一般 JSONL/manifest 物理事务回滚。本轮沿用该既有机制；不声称具有完整磁盘事务，也不删除可能属于既有会话的文件。
- Runtime lore reader 对损坏数据宽容并可能回退镜像，适合聊天降级，不适合权威导出。新导出路径明确区分不存在与损坏；损坏 canonical 数据报错，空对象/删除 tombstone 不复活旧镜像。
- 补齐场景、默认/备选开场与示例的可编辑入口；逐项处理多行备选，明确保存/清空。按当前受支持字段覆盖原始归档，保留未知扩展，但不激活系统提示、脚本或不支持的世界书规则。
- 交叉复核补齐原生 lore 重复 ID 的循环唯一化，避免初始化映射覆盖条目；profile 的存在但为 null 与缺失区分，lore 的 null 仍保留既有删除标记语义。
- 卡片编辑按字段保留未保存文本且仅写已编辑字段，避免其它字段刷新后被旧值覆盖；移除会卸载编辑器的冗余 reload，集成回归先复现再修复采纳后丢稿。
- 最后复核将拒绝已有 SessionManager/restore 的守卫前移到 createSession 入口，在任何 runtime teardown、焦点或待选模型状态修改之前失败；新增真实已注册 runtime 回归，105项定向通过。该修复只改变 session-jsonl 协调器源码哈希，重新只读比对后兼容封印。
- 新建开场成功后的页面导航保留已选择的准确会话，不再次按最近修改时间选择会话。
- 卡片不携带主动输出授权开关，缺省沿用既有关闭值。
- 冷角色的既有 Agent.init 仍可能启动外观摘要或记忆维护；零生成保证针对试演之外的开场文本写入和额外会话刷新，不冒称整个冷启动无后台请求。
- 旧 UI 测试的宽泛「保存」选择器与新增按钮冲突，改为准确定位原按钮，保留行为断言。
