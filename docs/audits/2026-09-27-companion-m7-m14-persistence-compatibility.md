The registry gains `channel-post-effects` and `agent-experience-versions` (62 to 64 stores). Existing `channels`, `xingye-state`, and `desktop-window-version-state` store-local contracts are updated. The schema entries also change for `agent-authored-records`, `agent-profile`, and `plugin-task-registry` because their guarded sources changed. The sixteen added mappings take the site count from 872 to 888: four each in `lib/task-outcome/effect-ledger.ts`, `lib/tools/experience-versions.ts`, `lib/xingye/topic-candidates.js`, and `desktop/main.cjs`. Every site has a concrete owner. No exemption or scanner rule was loosened.

The upgrade guarantee is that the new code reads existing local data without an epoch migration. This review does not promise old binaries understand newly written receipt markers or version ledgers, nor does it establish a cross-process exactly-once guarantee for channel posts. A channel receipt establishes a local append, not recipient delivery or reading.
