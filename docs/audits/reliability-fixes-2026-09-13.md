## 复审补充

- 文档保存按实例、文件和连接归属串行处理；迟到确认不会重发已接受的写入，后续保存使用确认后的版本。修复置顶队列遇错后滞留、快捷聊天断线锁定及旧发送清空新草稿。
- 角色资料覆盖加载失败、规范化保存和请求期间继续编辑；群聊生成内部等待点也检查连接变化，切走再切回仍使旧操作失效。同一 renderer 的并发提醒合并执行。
- SDK 输入所有权持续覆盖准备阶段，恢复/重载不会替换正在准备的会话；取消附件提交后不再登记文件。子 workflow 的错误被根脚本捕获后，可正常恢复，同时仍等待子任务退出。
- 资源事件游标、订阅及清理请求绑定原连接；切换服务器使旧订阅失效，由当前界面重新订阅当前资源，已清空的预览和工作区不会被旧快照重新订阅。
- 深度记忆的提取失败计数与存储失败分离；事实写入与来源修订收据在同一事务提交。检查点先等哈希读取句柄关闭，再以有界 Windows 重试发布。
- Windows 凭据文件原子替换遇短暂 EPERM/EACCES/EBUSY 时，最多尝试 6 次，同步等待合计不超过 310ms；持续失败保留旧文件并抛错，POSIX 权限策略不变。
- 频道写锁内的成员、取消和启用状态检查覆盖实际调用链。私聊测试夹具改用真实私聊 API，保留导出和归属隔离断言。
- 持久化登记、schema 指纹和 CLI 依赖清单已按最终实现重新生成；兼容性依据见 [持久化兼容性审查](2026-09-13-persistence-compatibility-review.md)。
