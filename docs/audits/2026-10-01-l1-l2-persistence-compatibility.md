- **agent-scoped-memory-derivations (new):** `agents/{agentId}/memory/scoped-derivations.v1.json` is an independent version-1 source/artifact/head manifest, atomically replaced by ScopedDerivationStore. Missing file is an empty store. Source session/entry identity, content hash, revision, generation and tombstone status establish validity. An optional separate write fence rejects pre-invalidation asynchronous writes after compensation without changing the content-identity generation of restored, unchanged evidence. Artifacts retain dependencies and current heads; stale or superseded artifacts remain on disk but are excluded from model context. It never reconstructs an explicit scope from legacy Markdown. The registry checkpoints this manifest with source JSONL, facts and related pin/summary records, then requires dependency revalidation on restore.
- **agent-memory:** Existing Markdown, rolling-summary and version-1 pin stores remain readable. Optional scope, provenance and source-status fields preserve new explicit context without changing the legacy file locations. Scoped pins do not enter the lossy legacy `pinned.md` projection. Original historical aggregates remain intact and are excluded from explicit scope queries. Source hashes and entry dependencies are retained on current records.
- **session-jsonl:** `hana-memory-scope` custom entries and dialogue-variant metadata use the existing Pi custom-entry protocol. No scope record means legacy; a malformed explicit record fails closed. Explicit scope markers are flushed before head publication. If head publication fails before or after writing, a flushed descendant compensation entry restores the previous scope; cold append recovery cannot reactivate the failed desired scope. Stable session and entry IDs establish ownership, not mutable session paths. Dialogue revisions do not undo external effects; retry uses the separately registered effect ledger.
- **xingye-state:** Optional scope/provenance metadata remains inside its existing agent-owned tree. Canonical scoped lore is filtered before prompt selection. Unscoped Markdown mirrors are legacy-only; unreadable or empty authoritative stores cannot resurrect stale mirror content. Scoped profile/card data is excluded from ordinary Phone context.
